# Pluto: the Supabase integration

The Supabase packages of [Pluto](https://github.com/plutocms/pluto), in one Bun workspace.

| Package                                            | npm                                                                                |
| -------------------------------------------------- | ---------------------------------------------------------------------------------- |
| [`packages/supabase`](packages/supabase)           | [`@plutocms/supabase`](https://www.npmjs.com/package/@plutocms/supabase)           |
| [`packages/supabase-shop`](packages/supabase-shop) | [`@plutocms/supabase-shop`](https://www.npmjs.com/package/@plutocms/supabase-shop) |
| [`packages/supabase-blog`](packages/supabase-blog) | [`@plutocms/supabase-blog`](https://www.npmjs.com/package/@plutocms/supabase-blog) |

Run `bun install`, then `bun run lint`, `bun run typecheck`, `bun run test` and `bun run build`.
